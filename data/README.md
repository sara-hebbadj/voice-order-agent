# Data

**All data here is synthetic.** Lumi Skin is a fictional skincare shop. No real company,
customer or order data is used. People are invented, emails use `@example.com` and phones
use the fake `+971 50 000 xxxx` pattern.

Source: shared synthetic Lumi Skin data, generated by `generate.py` (seed 42), the same
base data as the companion project `shop-support-agent` (P1). The three files below were
copied unchanged on 8 October 2026 so that this repository is self-contained.

| File | Rows | Used for | SHA-256 |
|---|---|---|---|
| `orders.csv` | 200 | order status, dates, tracking ID | `bc4c2318d6fa3e607332b3b679561e20e5812e5e0d9b11661feefaeed6230ca1` |
| `customers.csv` | 60 | only the last 4 phone digits, for caller verification | `acad821b5bca1a08e65a1c8fbd8b8af3028ed3323983399e265de3e3acb89676` |
| `tracking_events.csv` | 654 | courier events (picked up, in transit, out for delivery, delivered, failed attempt) | `8ad734135a1fba8d3e5430c90a365afaf7fc644e0e56ccde9e5d381c1652c19f` |

The data's "today" is 2026-10-08. Status mix: 15 processing, 30 shipped, 120 delivered,
15 returned, 20 cancelled.

The mock API (`src/voice_agent/mock_api.py`) returns only what the agent needs: order
status, dates, tracking ID, destination country and the **last 4** phone digits. It never
returns names, emails, addresses or full phone numbers.

If you change these files, rebuild the test calls: `python -m evals.build_calls`.
